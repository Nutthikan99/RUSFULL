วิธีสร้าง

TC1.1 สร้างใหม่
สร้างข้อมูลพื้นฐานของปฏิทิน แล้วเพิ่มกิจกรรมได้ไม่จำกัดก่อนบันทึกหรือพิมพ์ตัวอย่าง
คัดลอกเฉพาะข้อมูลปฏิทินและรายการกิจกรรม ไม่คัดลอก Section / ผู้สอน / Transaction ของ STEP อื่น
หลังคัดลอก ระบบจะเลื่อนปีของวันที่ตามปีการศึกษาปลายทางโดยอัตโนมัติ วันที่ที่เลื่อนเป็นเพียงค่าเริ่มต้น ต้องตรวจสอบกับประกาศ/วันหยุดจริงก่อนประกาศใช้

A. ข้อมูลพื้นฐานปฏิทิน

ระบุว่าปฏิทินฉบับนี้ใช้กับปี/ภาคและกลุ่มนักศึกษาใด
เงื่อนไขเป็นค่าคงที่ระบบ + ปีจาก Master ปีการศึกษา
MASTER SYSTEM 1 → M1 ระดับการศึกษา
MASTER SYSTEM 1 → M1 รูปแบบ / ภาคการศึกษา
เลือกได้หลายหลักสูตรจาก MASTER SYSTEM 1 → M2 หลักสูตรกลาง
เลือกได้หลายสาขาวิชาจาก MASTER SYSTEM 1 → M1 สาขาวิชา
System Status ใช้ควบคุมการเผยแพร่ปฏิทิน

B. รายการกิจกรรม

เพิ่มกิจกรรมได้ตลอด และกิจกรรมขั้นตอนเดียวกันสามารถมีหลายบรรทัด/หลายช่วงวันที่ได้
0 รายการ
ขั้นตอนวันที่เริ่มต้นวันที่สิ้นสุดกิจกรรมรายละเอียดจัดการ
ยังไม่มีกิจกรรม กด “+ เพิ่มกิจกรรม” เพื่อเริ่มสร้างรายการในปฏิทิน
ยกเลิก

เพิ่มกิจกรรม

หนึ่งขั้นตอนสามารถมีหลายบรรทัดได้ เช่น วันเปิดภาคของภาคปกติและภาคสมทบ

ดึงจาก MASTER SYSTEM 1 → M3 ประเภทกิจกรรมปฏิทิน
กรณีเป็นวันเดียว ปล่อยว่างได้
