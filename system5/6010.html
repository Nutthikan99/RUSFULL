ประเภทคำร้องและเงื่อนไข

บริหารประเภทคำร้องตาม TOR 5.6 ครบทุกประเภท พร้อมเงื่อนไข เอกสาร สายอนุมัติ ค่าธรรมเนียม และระบบงานที่รับผลไปดำเนินการ
+ สร้างประเภทคำร้อง
TOR 5.6 ครบ 20 รายการ
รหัส / ประเภทคำร้องหมวดระบบงานที่รับผลไปดำเนินการค่าธรรมเนียมสายอนุมัติหลักสถานะจัดการ
REQTYPE-01
บัตรนักศึกษา		ข้อมูลนักศึกษาระบบทะเบียนและข้อมูลนักศึกษาตามกรณีนักศึกษา → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-02
คำร้องทั่วไป		คำร้องทั่วไปหน่วยงานผู้รับผิดชอบตามเรื่องตามประเภทนักศึกษา → เจ้าหน้าที่ผู้รับผิดชอบใช้งานดู/จัดการ
REQTYPE-03
ลาพักการศึกษา / รักษาสภาพ		สถานภาพนักศึกษาระบบทะเบียนมีนักศึกษา → ที่ปรึกษา → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-04
เพิ่มรายวิชา		การลงทะเบียนระบบลงทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-05
ถอนรายวิชา		การลงทะเบียนระบบลงทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-06
ลาออกจากการเป็นนักศึกษา		สถานภาพนักศึกษาระบบทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → หัวหน้าสาขา → ทะเบียนใช้งานดู/จัดการ
REQTYPE-07
ลงทะเบียนเรียนข้ามศูนย์ศึกษา		การลงทะเบียนระบบลงทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → หน่วยงานต้นทาง/ปลายทางใช้งานดู/จัดการ
REQTYPE-08
ขอสอบพิเศษเพื่อการเทียบโอนหน่วยกิต		เทียบโอน/สอบพิเศษระบบเทียบโอนผลการศึกษามีนักศึกษา → ที่ปรึกษา → ผู้รับผิดชอบการเทียบโอนใช้งานดู/จัดการ
REQTYPE-09
ขอยกเว้นการเรียนรายวิชา		ผลการศึกษาระบบประมวลผลการศึกษาไม่มีนักศึกษา → อาจารย์ผู้สอน → ผู้มีอำนาจอนุมัติใช้งานดู/จัดการ
REQTYPE-10
ขอแก้ระดับคะแนนไม่สมบูรณ์ (I)		ผลการศึกษาระบบประมวลผลการศึกษาไม่มีนักศึกษา → อาจารย์ผู้สอน → ผู้มีอำนาจอนุมัติใช้งานดู/จัดการ
REQTYPE-11
ขอสอบนอกเวลาที่กำหนดในการสอบ		การสอบระบบทะเบียน / หน่วยงานจัดสอบตามเงื่อนไขนักศึกษา → อาจารย์ผู้สอน → ผู้รับผิดชอบการสอบใช้งานดู/จัดการ
REQTYPE-12
ลงทะเบียนเรียนต่างหลักสูตร		การลงทะเบียนระบบลงทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → หลักสูตร → ทะเบียนใช้งานดู/จัดการ
REQTYPE-13
เลื่อนรับพระราชทานปริญญาบัตร		สำเร็จการศึกษางานทะเบียน/งานบัณฑิตตามประกาศบัณฑิต → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-14
ลงทะเบียนเรียนเน้น / แทน		การลงทะเบียนระบบลงทะเบียนตามเงื่อนไขนักศึกษา → ที่ปรึกษา → เจ้าหน้าที่ทะเบียนใช้งานดู/จัดการ
REQTYPE-15
ขอเข้าสอบกองกลางการสอบ		การสอบหน่วยงานจัดสอบตามเงื่อนไขนักศึกษา → อาจารย์/หน่วยงานจัดสอบใช้งานดู/จัดการ
REQTYPE-16
ขอย้ายคณะ / สาขาวิชา / ศูนย์พื้นที่		สถานภาพ/โครงสร้างการศึกษาระบบทะเบียนมีนักศึกษา → ที่ปรึกษา → ต้นสังกัด → ปลายทาง → ทะเบียนใช้งานดู/จัดการ
REQTYPE-17
ขอยกเว้นรายวิชาภาษาอังกฤษในหลักสูตร		ยกเว้นรายวิชาระบบทะเบียน / ระบบประมวลผลการศึกษาตามเงื่อนไขนักศึกษา → ที่ปรึกษา → หลักสูตร → ทะเบียนใช้งานดู/จัดการ
REQTYPE-18
อนุมัติส่งรายงานผลการศึกษา		ผลการศึกษาระบบประมวลผลการศึกษาไม่มีอาจารย์ผู้สอน → ผู้มีอำนาจอนุมัติใช้งานดู/จัดการ
REQTYPE-19
ตรวจสอบวุฒิการศึกษา		ตรวจสอบวุฒิระบบเอกสารและงานบริการมี/ตามกรณีผู้ยื่น → เจ้าหน้าที่ทะเบียน → ตรวจสอบ/รับรองใช้งานดู/จัดการ
REQTYPE-20
ขอสำเร็จการศึกษา		สำเร็จการศึกษาระบบลงทะเบียน / ระบบประมวลผลการศึกษา / ระบบการเงินและค่าธรรมเนียมมีนักศึกษา → ที่ปรึกษา → หัวหน้าสาขา → ประธานหลักสูตรใช้งานดู/จัดการ
