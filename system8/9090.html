การตั้งค่าระบบบัณฑิตศึกษา

Configuration ที่ SYSTEM 8 เป็นเจ้าของ ไม่สร้าง Master กลางซ้ำ

Workflow และ SLAการแจ้งเตือนIntegrationเลขที่เอกสารสิทธิ์การใช้งาน

Workflow และ SLA

กระบวนการSLAสายอนุมัติสถานะ
แต่งตั้งอาจารย์ที่ปรึกษา5 วันเจ้าหน้าที่ → ประธานหลักสูตร → คณะใช้งาน
อนุมัติหัวข้อ/เค้าโครง10 วันที่ปรึกษา → กรรมการ → ประธานหลักสูตรใช้งาน
คำขอสำเร็จการศึกษา7 วันที่ปรึกษา → ประธานหลักสูตร → บัณฑิตวิทยาลัยใช้งาน

สิทธิ์การใช้งาน

ใช้บัญชีผู้ใช้งานและสิทธิ์ส่วนกลางของระบบทะเบียนและประมวลผล โดย SYSTEM 8 กำหนด Role และ Data Scope ตามงานบัณฑิตศึกษา ไม่สร้างบัญชีผู้ใช้ซ้ำ

Roleขอบเขตข้อมูลสิทธิ์หลัก
เจ้าหน้าที่บัณฑิตศึกษาคณะ/หลักสูตรที่รับผิดชอบดูรายการ, ตรวจสอบ, ดำเนิน Workflow, รายงาน
อาจารย์ที่ปรึกษานักศึกษาที่อยู่ในความดูแลพิจารณา, ให้ความเห็น, รับรอง
ผู้อนุมัติตามสายอนุมัติอนุมัติ, ส่งกลับ, ไม่อนุมัติ
